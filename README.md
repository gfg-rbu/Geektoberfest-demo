# Geektoberfest

A minimal single-page site for **Geektoberfest**, by the GeeksforGeeks Campus Body at RBU. It teaches three things: **Git**, **GitHub** and your first **Pull Request**.

![Geektoberfest preview](repo_assets/main.png)
