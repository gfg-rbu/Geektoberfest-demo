# Contributing

Thanks for helping out. First-time contributors are welcome.

## Steps

1. **Fork** this repo on GitHub.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```
3. **Create a branch**:
   ```bash
   git checkout -b my-change
   ```
4. **Make your change.** Open `index.html` in a browser to test it.
5. **Commit**:
   ```bash
   git add .
   git commit -m "Short description of the change"
   ```
6. **Push**:
   ```bash
   git push origin my-change
   ```
7. **Open a Pull Request** from your branch to `main` on GitHub. Say what you changed and why.

## Guidelines

- Keep the project a single HTML file with inline CSS and JS.
- Keep it minimal. Don't add dependencies or frameworks.
- Match the existing style (neo-brutalist cards, same fonts and colors).
- One change per pull request.
- Be kind and respectful in reviews and discussions.

## Ideas

- Fix typos or improve the wording
- Improve accessibility or mobile layout
- Add a short section on `git pull`, `merge` or resolving conflicts
- Report bugs or suggest improvements by opening an issue
